# PC Engine / TurboGrafx-16 Hardware Reference Documentation

This directory contains foundational hardware documentation for the PC Engine (HuC6280 CPU, VDC, VCE, PSG, and sprites). These resources are preserved here to provide an offline, self-contained reference framework for the development of the native TaliForth2 PC Engine development kit.

## Attribution & Credits

The reference text files in this folder (`concepts.txt`, `cpu_inst.txt`, `cpu.txt`, `library.txt`, `psg.txt`, `sprites.txt`, `vce.txt`, and `vdc.txt`) were originally authored by **David Shadoff** as part of the historic **MagicKit / Magic Assembler** homebrew tools development project. 

These documents have been a cornerstone of the PC Engine homebrew community for decades. They are included here as public domain/freeware community reference materials with maximum gratitude for his massive contributions to documenting this platform's hardware layouts.
